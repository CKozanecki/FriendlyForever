# Security policy

Friendly Forever runs inside World of Warcraft and only uses the game's addon API. It never reads or sends anything outside the game, and it only stores its own settings in `WTF/.../SavedVariables/FriendlyForever.lua`.

## Reporting a problem

If you find something that could harm players (for example, a way to make the addon send chat a player didn't intend, spam a channel, or break Blizzard's UI), please report it privately through **Security → Report a vulnerability** on this repository, not as a public issue.

You'll get a reply within a week. Fixes ship as a new release on CurseForge, and the changelog credits you unless you'd rather it didn't.

## Supported versions

Only the latest release gets fixes.
