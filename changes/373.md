- **Buff mode no longer takes a moment the game can't say you're in a group as leaving it:** if, in the middle of a session, the game gave no readable answer for one group change, buff mode treated it as leaving and then joining again. It forgot who was missing your buffs, so a buff missing all along turned buff mode back on after you'd turned it off ("Turn on when I join a group" could also turn it on), and it forgot the group's first pull. That group change now changes nothing, and the next one the game can answer decides. After a `/reload` the game can't yet answer, buff mode now asks again every few seconds instead of waiting for the group to change. (#373)
