- **Your settings stay put at login:** a character that never chose a profile, logging in while a shared profile is active, now gets a profile of its own, named after it ("Ann", or "Ann 2" if that name is taken) and copied from the settings you had, instead of falling back to the stored Default profile, which could quietly turn buff back, passers-by or buff requests off. It never joins the shared profile, and Default and your other profiles are left as they were. With Default active, a new character starts on Default, as before. With the most profiles allowed (20), it keeps the active one, and chat says why. A character 1.5.2 already moved to Default goes back with `/friendly profile use <name>`: that profile's settings were saved before the switch (#519)
