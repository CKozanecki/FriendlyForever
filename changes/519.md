- **Your profile stays put at login:** a character that never chose a profile now keeps the profile that was active, as 1.5.1 did, and remembers it as its own, instead of falling back to the stored Default profile, which could quietly turn buff back, passers-by or buff requests off. Only a new character with Default active starts on Default. A character 1.5.2 already moved to Default goes back with `/friendly profile use <name>`: that profile's settings were saved before the switch (#519)
