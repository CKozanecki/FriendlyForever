- **Level-up congratulations.** A new **Level Up** message congratulates a party member who levels up, in party chat (or instance chat in a dungeon-finder group). It is on by default, waits 3 seconds, and doesn't repeat to the same player for 60 seconds. It stays quiet in raids, battlegrounds and arenas, and never for your own level-up. It has its own tab, with 30 fantasy lines and a casual set to load. This version adds a file: restart the game (not /reload) after updating. (#273)
